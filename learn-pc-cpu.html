The processor (CPU)

The processor runs every program on the computer. Each instruction, from moving the mouse to working out a game's physics, passes through it.

Processor

What it does

A program is a long list of small steps: add these numbers, compare those, fetch this from memory. The processor works through those steps billions of times a second. It does this on several cores at once, and each core is a complete worker of its own. Some jobs split neatly across cores, such as exporting video or compiling code. Others mostly wait on one core, which is true of many games. That is why both the number of cores and the speed of each core matter.

Many processors also have a small graphics unit built in. It is enough for a desktop and video, but not for demanding games. A processor without one needs a graphics card to show any picture at all.

Socket Must match the motherboard exactly. The shape and contact layout of the processor's underside. It must match the motherboard's socket exactly. This is the first thing to check, and the most common mistake. Examples: AM5, LGA 1851.
AM5
Cores and threads More cores do more jobs at once. Cores are separate workers. A thread is a stream of work a core keeps going; some cores handle two at once. More cores help most with work that splits up. Examples: 8 cores, 16 threads.
8 cores
Clock speed Higher is faster, within one generation. How many steps a core takes per second, in billions. Boost is the top speed for short bursts while the processor is cool enough. Only compare clock speeds within the same generation: newer designs do more per step. Examples: 4.2 GHz base, up to 5.4 GHz boost.
5.4 GHz
Power Sets how strong the cooler and power supply must be. Roughly how much heat the processor gives off under load, in watts. Makers call it TDP or base power, and most list a higher maximum too, which many processors hold for as long as the load lasts. Size the cooler and power supply for the higher figure. The cooler has to remove it and the power supply has to provide it. Examples: 65 W, 120 W.
120 W
Cache Fast memory on the chip; more helps some games. A small store of very fast memory on the chip itself. A bigger cache means fewer trips out to the RAM, which helps some games noticeably. Examples: 32 MB.
32 MB
Memory support Which kind of RAM it can use. Which generation of RAM the processor can drive. The motherboard settles the final choice: a board has DDR4 slots or DDR5 slots, never both. Examples: DDR5 only.
DDR5
Built-in graphics Can it show a picture without a graphics card? Whether the processor can drive a monitor on its own, through the motherboard's video ports. Examples: yes / no.

How it connects
  • Motherboard socket: It sits in the socket, held down by a lever or a frame. A small triangle on one corner shows which way round it goes.
  • Cooler: The cooler presses on top, with a thin layer of thermal paste between them to carry the heat across.
  • Memory: The processor talks to the RAM directly, through lines running from the socket to the memory slots.
  • Graphics card and fast drives: The processor's own PCIe lanes run to the main graphics slot and usually to the first M.2 slot.
  • Power: A separate 8-pin cable (sometimes two) from the power supply plugs in near the top of the board. It is labelled CPU or EPS.
Before you buy
  • Make sure the socket matches the motherboard.
  • Find this exact processor in the motherboard maker's CPU support list. It may need a newer BIOS than the board shipped with.
  • Check that the cooler fits the socket and can handle the processor's power. Many processors come without a cooler.
  • No built-in graphics? Then you need a graphics card.
Why might a processor with the right socket still not start?

The socket only means it fits physically. The board's firmware (BIOS) also has to know the processor, so a board made before the processor came out may need an update first. Some boards can update the BIOS from a USB stick with no processor installed. The support list says which BIOS version is needed.
