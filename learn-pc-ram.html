Memory (RAM)

Memory is the computer's short-term workspace: fast space for whatever is running right now. It is wiped every time the power goes off.

Memory

What it does

Programs and files live on the drive, but the processor can't work on them there: the drive is far too slow. So whatever you're using is copied into memory, where the processor can reach it in well under a millionth of a second.

More memory means more programs, browser tabs and game data can stay ready at once. When memory runs out, the computer parks some of it on the drive instead, and everything slows down.

Memory

Typical 16–64 GB

RAM Volatile working memory: holds running programs and their data for the CPU at high speed.

Type DDR4 or DDR5: must match the motherboard. The memory generation. The two have their notch in different places, so a stick physically fits only its own kind of slot. The motherboard decides which one you need. Examples: DDR4 or DDR5.
DDR5
Capacity More lets you keep more open at once. How much the kit holds in total, and how it's split across sticks. Examples: 32 GB (2 × 16 GB).

Kit size Buy a matched pair for full speed. Memory works fastest in pairs (dual channel). Buy the sticks as one kit, so they're matched, and put them in the slots the board's manual names, often the second and fourth. Examples: 2 sticks.
2 sticks
Speed and latency Higher speed and lower CL are faster. How fast data moves, and how long each request waits. The rated speed usually needs the kit's memory profile turned on in the BIOS; without it, the memory runs at a slower default. Examples: 6000 MT/s, CL30.

Connects to Memory slots · Processor

How it connects
  • Memory slots: Next to the processor socket. Clips at the ends lock the stick in when it's pushed down firmly.
  • Processor: The memory controller is inside the processor, so the lines run straight from the slots to the socket.
Before you buy
  • The type matches the motherboard (DDR4 or DDR5).
  • The kit doesn't have more sticks than the board has slots.
  • For the best chance of reaching the rated speed, look for the kit on the board maker's memory support list (often called the QVL).
  • With a big air cooler, check that the memory isn't too tall.
Why does a new computer sometimes take a minute to start the first time?

On the first start, the board tests and tunes its timing with each memory stick. With DDR5 this can take a minute or more, and the screen may stay black. Let it finish rather than switching off.
