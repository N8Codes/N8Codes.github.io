# Privacy Policy

**Character sheets** (`sheets.html`) — Last updated: November 2026

## Summary

The character sheets run entirely in your browser. Your characters stay on
your device: nothing you type is sent to N8Codes or to anyone else. There is
no account, no cookies, no analytics and no tracking. The page itself keeps
nothing unless you turn on "Keep a copy in this browser". When you export a
character, your browser saves it as a file on your device, like any download;
it isn't sent anywhere.

## Data Collection

The developer collects **nothing**. The page has no server of its own, no
analytics, no telemetry and no crash reporting. It contains no code that sends
anything over the network, and its security policy tells your browser to block
any such request.

## Hosting

The page is hosted on GitHub Pages. As with any website, when your browser
loads the page, GitHub receives the usual request details, such as your IP
address and browser type, under the
[GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
N8Codes doesn't receive those details. The page loads nothing from any other
site.

## Your Characters

- **On screen.** While you fill in a sheet, the character exists only in the
  open page. Closing or reloading the page discards it, unless you exported
  it or turned on the browser copy. While the browser copy is off, the page
  warns you before you leave with changes you haven't exported.
- **Export.** "Export JSON" and "Export .txt" create a file in your browser
  and save it with your browser's normal download. The file goes wherever
  your browser saves downloads. It is not uploaded anywhere.
- **Import.** "Import JSON" reads a file you choose, in your browser only. The
  page reads it as data and keeps only the character fields it recognises.
  The file is never sent anywhere.
- **Random characters** are rolled in your browser.

## Optional Browser Copy

If you turn on **Keep a copy in this browser** (in the File menu), the page
stores the character on each game system's tab in your browser's local
storage, on your device only, so it is still there when you come back to the
page. It stores the same contents as an exported file, plus one setting that
remembers the switch is on. Nothing in local storage is sent anywhere.

To delete it, turn the switch off. Clearing this site's data in your browser
settings also deletes it.
